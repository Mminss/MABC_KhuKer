# 공지 충돌 탐지기 (Notice Conflict Detector)

여러 채널에 올린 공지문에서 **어긋난 지점만 찾아주는** 도구입니다.

- 이 서비스는 **Vercel에 배포**되는 공개 웹 서비스 MVP입니다.
- 사용자는 계정 없이 URL로 접속하며, 비밀(키)을 입력하지 않습니다.
- 백엔드는 슬랙 연동을 통해 공지를 감지하고, notice-conflict 로직으로 대조합니다.

---

## 프로젝트 개요

- **목적**: 여러 채널에 올린 공지 간 날짜/시간/장소/참가비/신청링크/마감일 등이 서로 다른 지점을 탐지
- **대상**: 동아리·모임·행사 운영진 (채널별 공지를 확인하고 대조하는 사람)
- **핵심 기능**:
  - 공지 입력 및 게시 플랫폼 선택 (복수 선택 가능)
  - 슬랙 연동으로 공지 감지 (실제 연동 또는 시연용)
  - notice-conflict 방식의 항목 대조 (일치/어긋남/정보 없음/판별 불가)
  - 충돌 알림 팝업 및 항목별 대조 결과 표시
  - 전체 수정 반영 시 다른 플랫폼 UI 업데이트 (가상 UI 반영)

---

## 사용 방법

1. **공지 입력**: 왼쪽에 제목, 날짜, 시간, 장소, 참가비, 신청 링크, 마감일을 입력
2. **플랫폼 선택**: 게시할 플랫폼 체크박스에서 선택 (슬랙, 카톡, 인스타, 신청폼, 텔레그램, 공지판)
3. **공지 올리기**: 버튼 클릭 시 선택된 플랫폼에 공지 반영
4. **충돌 감지**: 다른 플랫폼과 값이 다른 항목이 있으면 팝업 알림 표시
5. **확인/수정**: 항목별 대조 결과 확인 후 전체 수정 반영 또는 취소

---

## 기술 스택

- **프론트엔드**: HTML, CSS, JavaScript
- **백엔드**: 슬랙 API (봇 토큰 기반 읽기/쓰기) - 실제 연동 또는 시연용
- **배포**: Vercel

---

## 환경 변수 (필요 시)

실 슬랙 연동을 사용할 경우 필요한 환경변수 예시:

- `SLACK_BOT_TOKEN`: 슬랙 봇 토큰
- `SLACK_CHANNEL_ID`: 대상 채널 ID

> 실제 값은 코드에 직접 적지 않고 환경변수로 관리합니다.

---

## 시연 포인트

- 왼쪽 공지 입력 화면에서 공지를 작성하고 플랫폼 선택
- 오른쪽 채팅방에 이미 올려진 공지 현황 표시 (충돌 포인트 포함)
- 공지 올리기 시 슬랙 연동으로 감지, 다른 플랫폼과 대조
- 충돌 알림 팝업에서 어긋난 항목 강조 표시
- 전체 수정 반영 시 다른 플랫폼 채팅방 UI 업데이트
